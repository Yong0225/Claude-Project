# Pulse — 生意数据追踪

单文件 Web 应用（`index.html`），零依赖、无需构建。手动记录每天 / 每周 / 每月的进度，转化率、CAC、LTV、利润等指标全部自动算好。界面可切 **English / 中文**，Apple 设计语言与弹簧动画。

## 运行

直接用浏览器打开 `business-tracker/index.html`。

若浏览器限制了 `file://` 的本地存储（数据保存不了），用本地服务器打开：

```bash
py -m http.server 8765 --directory business-tracker
```

然后访问 http://localhost:8765

数据保存在浏览器 localStorage（key: `pulse.v1`），不上传任何服务器。设置页可导出 / 导入 JSON 备份、导出 CSV（带 BOM，Excel 打开中文不乱码）。

## 五个页面

| 页面 | 作用 |
|------|------|
| 概览 | 周 / 月 / 季 / 年 / 全部切换，‹ › 翻看历史周期。6 个核心 KPI（收入、新客户、线索→客户转化率、CAC、净利润、LTV:CAC）带环比和迷你走势；趋势图（可按住拖动查看每个点）；转化漏斗；目标进度；自动洞察 |
| 记录 | **快速记录**：每个漏斗阶段一个 − / + 计数器，发生一件点一下，即时保存，可切换日期补录。**完整记录**：漏斗 + 收入 + 成本 + 流失客户 + 备注。历史按月分组，点开编辑，删除可撤销 |
| 指标 | 全部指标分组列出（漏斗 / 获客 / 收入与利润 / 留存与价值 / 自定义 / 原始数据），每项显示公式、当期值与环比。点开看 12 期走势、代入的具体数字、健康标准 |
| 目标 | 任意指标都能设目标（按周 / 月 / 季 / 年）。圆环进度，累加型指标（收入、新客户等）按已过天数推算「按目前速度预计」，越低越好的指标（CAC、成本）按上限判断 |
| 设置 | 商家名、语言、货币、深浅色；开始记录前已有客户数、客户生命周期上限；**漏斗阶段可改名 / 排序 / 增删**；自定义指标；数据备份 |

## 输入字段

每条记录对应一个日期（同一天只有一条，重复会合并）：

- **漏斗阶段**（默认：新线索 → 已触达 → 已回复 → 会议/通话 → 已报价 → 成交），最后一个阶段 = 新客户
- **收入**：新客户收入、续费 / 老客户收入
- **成本**：营销与广告、销售与工具、交付成本、其他支出
- **客户**：流失客户数

## 指标公式

| 指标 | 公式 |
|------|------|
| 阶段转化率 | 下一阶段 ÷ 上一阶段 |
| 线索 → 客户 | 最后阶段 ÷ 第一阶段 |
| CAC 获客成本 | (营销 + 销售与工具) ÷ 新客户 |
| 单条线索成本 / 单次会议成本 | (营销 + 销售与工具) ÷ 线索数 / 会议数 |
| 平均客单价 | 新客户收入 ÷ 新客户 |
| ROAS | 新客户收入 ÷ 营销与广告 |
| 获客投资回报 | (新客户收入 − 获客花费) ÷ 获客花费 |
| 毛利 / 毛利率 | 收入 − 交付成本；÷ 收入 |
| 净利润 / 净利率 | 收入 − 全部成本；÷ 收入 |
| 活跃客户 | 开始记录前已有客户 + 累计成交 − 累计流失 |
| 每客户月均收入 ARPA | 收入 ÷ 平均活跃客户 ÷ 月数 |
| 月流失率 | 流失客户 ÷ 期初客户 ÷ 月数 |
| LTV | ARPA × 毛利率 × min(1 ÷ 流失率, 生命周期上限) |
| LTV : CAC | LTV ÷ CAC |
| CAC 回本周期 | CAC ÷ (ARPA × 毛利率) |
| 自定义指标 | 任意指标 A ÷ 任意指标 B，可选数字 / 金额 / 百分比 / 倍数 |

两条让数字不骗人的规则：

- **同期对比**：周期还没结束时，环比拿的是上一期**相同天数**（9 月前 12 天对比 8 月前 12 天），不会因为本月还没过完就显示下滑。
- **单位经济指标取 90 天**：ARPA、流失率、LTV、LTV:CAC、回本周期在周期短于 90 天时，自动用截至该周期末的最近 90 天计算（不早于第一条记录），避免某一周没流失就算出无限大的 LTV。

## 交互与动画

- 自写弹簧引擎（Apple 的 damping + response 参数），所有动画从屏幕上的当前值出发、保留速度，随时可打断
- 数字滚动、漏斗条、目标圆环在重绘后从旧值过渡到新值，而不是从 0 重来
- 分段控件滑块、周期标签按翻页方向滑入；图表切换数据时曲线形变过渡，切换指标类型时重新绘入
- 手机端底部面板可下拉关闭（动量投影 + 越界橡皮筋），桌面端居中弹出
- 顶栏、侧边栏、标签栏为 `backdrop-filter` 半透明材质；大标题滚动后收进顶栏
- 适配 `prefers-reduced-motion` / `prefers-reduced-transparency` / `prefers-contrast`、深色模式

## 快捷键

`N` 新记录 · `1`–`5` 切换页面 · `←` / `→` 上一期 / 下一期 · `Esc` 关闭面板
