# Pulse — 生意数据追踪

单文件 Web 应用（`index.html`），零依赖、无需构建。手动记录每天 / 每周 / 每月的进度，转化率、CAC、LTV、利润等指标全部自动算好。界面可切 **English / 中文**，Apple 设计语言与弹簧动画。

## 运行

直接用浏览器打开 `business-tracker/index.html`。

若浏览器限制了 `file://` 的本地存储（数据保存不了），用本地服务器打开：

```bash
py -m http.server 8765 --directory business-tracker
```

然后访问 http://localhost:8765

每次改动立刻保存在本机浏览器（localStorage，key: `pulse.v1`）。开启**云同步**后同时保存到 Supabase，电脑、手机自动同步（见下文）。设置页也可导出 / 导入 JSON 备份、导出 CSV（带 BOM，Excel 打开中文不乱码）。

## 五个页面

| 页面 | 作用 |
|------|------|
| 概览 | 周 / 月 / 季 / 年 / 全部切换，‹ › 翻看历史周期。6 个核心 KPI（收入、新客户、线索→客户转化率、CAC、净利润、LTV:CAC）带环比和迷你走势；趋势图（可按住拖动查看每个点）；转化漏斗；目标进度；自动洞察 |
| 记录 | **快速记录**：每个漏斗阶段一个 − / + 计数器，发生一件点一下，即时保存，可切换日期补录。**完整记录**：漏斗 + 收入 + 成本 + 流失客户 + 备注。历史按月分组，点开编辑，删除可撤销 |
| 指标 | 全部指标分组列出（漏斗 / 获客 / 收入与利润 / 留存与价值 / 自定义 / 原始数据），每项显示公式、当期值与环比。点开看 12 期走势、代入的具体数字、健康标准 |
| 目标 | 任意指标都能设目标（按周 / 月 / 季 / 年）。圆环进度，累加型指标（收入、新客户等）按已过天数推算「按目前速度预计」，越低越好的指标（CAC、成本）按上限判断 |
| 设置 | 商家名、语言、货币、深浅色；开始记录前已有客户数、客户生命周期上限；**漏斗阶段可改名 / 排序 / 增删**；自定义指标；**云同步**；数据备份 |

## 输入字段

每条记录对应一个日期（同一天只有一条，重复会合并）：

- **漏斗阶段**（默认：新线索 → 已触达 → 已回复 → 会议/通话 → 已报价 → 成交），最后一个阶段 = 新客户
- **收入**：新客户收入、续费 / 老客户收入
- **成本**：营销与广告、销售与工具、交付成本、其他支出
- **客户**：流失客户数

## 指标公式

| 指标 | 公式 |
|------|------|
| 阶段转化率 | 下一阶段 ÷ 上一阶段 |
| 线索 → 客户 | 最后阶段 ÷ 第一阶段 |
| CAC 获客成本 | (营销 + 销售与工具) ÷ 新客户 |
| 单条线索成本 / 单次会议成本 | (营销 + 销售与工具) ÷ 线索数 / 会议数 |
| 平均客单价 | 新客户收入 ÷ 新客户 |
| ROAS | 新客户收入 ÷ 营销与广告 |
| 获客投资回报 | (新客户收入 − 获客花费) ÷ 获客花费 |
| 毛利 / 毛利率 | 收入 − 交付成本；÷ 收入 |
| 净利润 / 净利率 | 收入 − 全部成本；÷ 收入 |
| 活跃客户 | 开始记录前已有客户 + 累计成交 − 累计流失 |
| 每客户月均收入 ARPA | 收入 ÷ 平均活跃客户 ÷ 月数 |
| 月流失率 | 流失客户 ÷ 期初客户 ÷ 月数 |
| LTV | ARPA × 毛利率 × min(1 ÷ 流失率, 生命周期上限) |
| LTV : CAC | LTV ÷ CAC |
| CAC 回本周期 | CAC ÷ (ARPA × 毛利率) |
| 自定义指标 | 任意指标 A ÷ 任意指标 B，可选数字 / 金额 / 百分比 / 倍数 |

两条让数字不骗人的规则：

- **同期对比**：周期还没结束时，环比拿的是上一期**相同天数**（9 月前 12 天对比 8 月前 12 天），不会因为本月还没过完就显示下滑。
- **单位经济指标取 90 天**：ARPA、流失率、LTV、LTV:CAC、回本周期在周期短于 90 天时，自动用截至该周期末的最近 90 天计算（不早于第一条记录），避免某一周没流失就算出无限大的 LTV。

## A/B 测试

对比不同的开场白、邮件标题、报价方案，而不是全部混在一起算：

1. 指标 → 顶部切到 **A/B 测试** → **新建测试**，比如「开场白」，下面加版本「赞美式」「痛点式」（至少 2 个）
2. 记录 → 快速记录上方选择版本，再点 + ；完整记录里也有「测试版本」
3. 回到 A/B 测试，看每个版本的逐级转化率并排对比

- 记录按「日期 + 版本」区分，同一天每个版本各一条；**记在版本下的数字同样计入总数**，概览和其他指标照常计算
- 对比从这个测试里第一个有数据的阶段开始，比如只记了已触达 / 已打开 / 已回复，就只比打开率和回复率
- 每一行用双比例 z 检验比较最好和第二好的版本：两者基数都 ≥ 30 且 |z| ≥ 1.96 才显示「胜出 · 95% 置信」，否则显示「差距还不显著」或「样本太少」
- 删除测试不会删数据，只是这些数字不再按版本对比

## 改名

漏斗转化率默认用行业术语：触达率、打开率、回复率、约见率、报价率、成交率（阶段顺序是默认的才会套用，否则显示「A → B」）。

**点名字就能直接改**，不需要额外按钮：指标页的每一行、指标详情的标题、快速记录里的阶段名、A/B 测试表格的行名。回车保存，Esc 取消，清空就恢复默认名。改阶段名等于改漏斗阶段（和设置里一样），改自定义指标就是改它的名称，其他指标的名字存在 `names`，会跟着云同步。

## 云同步

不用注册账号，用**同步密钥**连接设备：

1. 电脑上：设置 → 云同步 → **开启云同步**。当前数据上传到云端，自动弹出一个 8 位**配对码**（10 分钟有效）
2. 手机上：打开 Pulse → 设置 → 云同步 → **连接已有同步** → 输入配对码
3. 之后两边自动同步：改动约 1 秒后上传；打开 App、切回 App、以及每 20 秒检查一次别的设备的改动。顶栏云朵图标的小圆点显示状态（绿 = 已同步，蓝 = 同步中，灰 = 离线，红 = 出错）

工作方式：

- **本地优先**：离线也能正常记录，联网后自动补传
- **按记录合并**：每条记录、目标、自定义指标都带修改时间（`u`），删除会留下墓碑（`del`，保留 180 天）。两台设备离线时各改各的，联网后两边的改动都保留；同一条记录两边都改了，以最后修改的为准
- 语言和深浅色是每台设备自己的设置，不同步
- 同步密钥存在 `pulse.sync`，**不会**出现在导出的备份文件里。设置 → 云同步 → 查看同步密钥，可存进密码管理器；换手机时在「连接已有同步」里粘贴密钥也能连上
- 点「开启云同步」时会先问「另一台设备已经开过了吗？」，开过就直接去「连接已有同步」，避免建出两份互不相通的云端数据
- 连接时如果这台设备本来就有数据，会显示两边各有多少，让你选：
  - **合并两边的数据**：两边都保留，这台设备的数据也会上传
  - **用云端数据替换这台设备**：这台设备变成和云端一模一样，**不产生删除标记**，云端一条都不会少。适合设备上只有示例 / 测试数据的情况。注意不要用「清除所有数据」代替它：清除会留下删除标记，连接后可能删掉云端同一天的真实记录
- 无论选哪个，都会先把这台设备原有的数据另存一份到 `pulse.v1.beforeSync`
- 数据格式版本 `fv`：服务器拒绝格式比云端旧的页面推送（返回 `outdated`，页面提示刷新），防止还开着的旧版页面把新字段（测试版本、自定义名称）覆盖掉

服务端（Supabase，与排班系统共用一个项目，Pulse 的表和函数都以 `pulse_` 开头，完整定义见 [`supabase.sql`](supabase.sql)）：

- 表全部锁死（开 RLS、无策略、无授权），只能通过校验密钥的函数访问；数据库里只存密钥的 SHA-256
- `pulse_push` 带版本号做乐观并发：版本对不上时返回云端最新数据，客户端合并后重传
- 配对码一次性、10 分钟过期；10 分钟内错 20 次暂停配对

## 交互与动画

- 自写弹簧引擎（Apple 的 damping + response 参数），所有动画从屏幕上的当前值出发、保留速度，随时可打断
- 数字滚动、漏斗条、目标圆环在重绘后从旧值过渡到新值，而不是从 0 重来
- 分段控件滑块、周期标签按翻页方向滑入；图表切换数据时曲线形变过渡，切换指标类型时重新绘入
- 手机端底部面板可下拉关闭（动量投影 + 越界橡皮筋），桌面端居中弹出
- 顶栏、侧边栏、标签栏为 `backdrop-filter` 半透明材质；大标题滚动后收进顶栏
- 适配 `prefers-reduced-motion` / `prefers-reduced-transparency` / `prefers-contrast`、深色模式

## 快捷键

`N` 新记录 · `1`–`5` 切换页面 · `←` / `→` 上一期 / 下一期 · `Esc` 关闭面板
